# 3D-экскурсия по помещению

Видео-проход по помещению свободного назначения (СПб, ≈73 м², 50 000 ₽/мес), собранный из 15 фотографий объявления.

- `tour.mp4` — готовое видео 1920×1080, 30 кадров/с, ~74 с.
- `index.html` — интерактивная версия в браузере: тот же проход, пауза, стрелки ← → между комнатами, клик по полосе прогресса.
- `photos/` — фото, вырезанные из скриншотов (кнопки сайта убраны).

## Как это сделано

Каждое фото превращается в 3D-«коробку» комнаты (техника *tour into the picture*): задний прямоугольник
стены в `rect`, пол, потолок и боковые стены — плоскости между ним и краями кадра. Фото проецируется на них
из точки съёмки, поэтому камера может войти в комнату и получить настоящий параллакс. Между комнатами — плавный переход.

Порядок комнат, подписи и направление взгляда (`pan`, `tilt`) правятся в массиве `SCENES` в `index.html`.

Запуск: `python3 -m http.server 8000` в корне репозитория → `http://localhost:8000/tour/`.
