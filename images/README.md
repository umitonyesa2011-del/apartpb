# Папка для фото барбера

Положите сюда фото мастера и назовите файл **`barber.jpg`** — оно автоматически
подставится в hero-блок и в блок «Мастер» на главной странице.

Пока файла нет — вместо фото показывается аккуратная эмблема-заглушка
«BARBER THE CULT», вёрстка не ломается.

**Как взять фото со страницы записи YClients:**
1. Откройте страницу записи мастера в YClients.
2. Сохраните фото профиля мастера себе на компьютер.
3. Переименуйте файл в `barber.jpg` и положите в эту папку (заменив старый, если есть).

**Рекомендации:** портретное фото (соотношение примерно 4:5), ширина от 800 px,
формат `.jpg`, вес до 400 КБ.
