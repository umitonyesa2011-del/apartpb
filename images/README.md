# Папка для фотографий квартир

Положите сюда фото и назовите файлы так, как указано в `assets/js/data.js`:

| Квартира | Имена файлов |
|---|---|
| 2-к., 55 м² | `apt-55-1.jpg`, `apt-55-2.jpg`, `apt-55-3.jpg` |
| 2-к., 65 м² | `apt-65-1.jpg`, `apt-65-2.jpg`, `apt-65-3.jpg` |
| 1-к., 27 м² | `apt-27-1.jpg`, `apt-27-2.jpg`, `apt-27-3.jpg` |
| 2-к., 62 м² | `apt-62-1.jpg`, `apt-62-2.jpg`, `apt-62-3.jpg` |
| 2-к., 57 м² | `apt-57-1.jpg`, `apt-57-2.jpg`, `apt-57-3.jpg` |

Пока файла нет — на сайте показывается аккуратная цветная заглушка, вёрстка не ломается.
Фото можно добавлять сколько угодно: просто допишите имя файла в массив `photos` нужной квартиры.

**Рекомендации:** горизонтальные фото, соотношение 4:3, ширина 1200–1600 px, формат `.jpg`, вес до 400 КБ.
