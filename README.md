# Лендинг посуточной аренды квартир — Санкт-Петербург

Одностраничный сайт для сдачи квартир посуточно: каталог квартир со ссылками на Avito,
онлайн-календарь бронирования с расчётом стоимости и заявкой в WhatsApp.

## Что на сайте

- **Главный экран** — анимированные градиентные линии, цифры: срок работы, отсутствие комиссии, время ответа.
- **Преимущества** — 6 блоков: без комиссий, заселение 24/7, чистота, документы для отчёта и др.
- **Квартиры** — 5 карточек: цена за сутки, район, площадь, спальные места, фото-слайдер,
  фильтры по количеству комнат и кнопка «Смотреть на Avito».
- **Календарь бронирования** — выбор квартиры, выбор дат заезда/выезда, подсчёт ночей и суммы,
  форма заявки. Заявка уходит готовым сообщением в WhatsApp на **+7 906 255-72-82**.
- **Отзывы, частые вопросы, контакты** — телефон, WhatsApp, плавающая кнопка звонка на мобильных.

## Как запустить

Сборка не нужна — это чистые HTML/CSS/JS. Достаточно открыть `index.html` в браузере
или поднять любой статический сервер:

```bash
python3 -m http.server 8000
```

Для публикации подойдёт GitHub Pages, Netlify, Vercel или любой хостинг статики.

## Что нужно заполнить

Avito закрывает автоматический доступ к объявлениям, поэтому цены, районы и фото
проставлены как заготовки. Всё содержимое находится в одном файле — **`assets/js/data.js`**:

1. `price` — реальная цена за сутки (число, без пробелов и знака ₽);
2. `district` — район или ближайшее метро («Центральный р-н, м. Маяковская»);
3. `photos` — имена файлов из папки `images/` (см. `images/README.md`);
4. `booked` — занятые даты в формате `'2026-08-20'`, они станут перечёркнутыми в календаре.

Там же меняются телефон (`CONTACTS`), цифры на главном экране (`STATS`),
отзывы (`REVIEWS`) и вопросы-ответы (`FAQ`).

## Структура

```
index.html              разметка страницы
assets/css/styles.css   стили, палитра и адаптив
assets/js/data.js       ← все тексты, цены, квартиры, контакты
assets/js/app.js        каталог, календарь, форма, галерея
images/                 фотографии квартир
```
