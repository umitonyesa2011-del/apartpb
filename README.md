# The Cult Barbershop — сайт-визитка

Одностраничный сайт для барбершопа одного мастера: главный экран, преимущества,
блок о мастере, прайс-лист с категориями услуг, форма записи (звонок или СМС
на номер мастера) и блок с адресом и картой.

## Что на сайте

- **Главный экран** — название «BARBERSHOP THE CULT», адрес, часы работы,
  кнопки «Записаться» и «Позвонить сейчас».
- **Преимущества** — 6 карточек: один мастер, классика барберинга, стерильный
  инструмент и т. д.
- **Мастер** — фото и краткое описание мастера.
- **Услуги и цены** — прайс-лист с вкладками по категориям, кнопка «Выбрать»
  у каждой услуги переносит её в форму записи.
- **Запись** — форма (имя, телефон, услуга, удобное время). После отправки
  показываются кнопки «Отправить СМС мастеру» (открывает приложение сообщений
  с готовым текстом на номер мастера) и «Позвонить мастеру».
- **Адрес** — «Адрес: проспект Медиков, 10 к1» + карта, плавающая кнопка
  звонка на мобильных.

## ⚠️ Что нужно проверить и заполнить

1. **Цены и услуги** — в `assets/js/data.js` (`PRICES`) перенесены со
   скриншотов страницы записи YClients. Если там появятся новые услуги или
   изменятся цены/длительность — правьте прямо в этом файле.
2. **Фото мастера** — положите файл `barber.jpg` в папку `images/`
   (см. `images/README.md`). Пока файла нет, вместо фото показывается
   эмблема-заглушка. Проще всего добавить файл через веб-интерфейс GitHub:
   откройте папку `images` в ветке `claude/barber-shop-website-g6owbt`,
   нажмите «Add file → Upload files», перетащите фото и назовите его
   `barber.jpg` — сайт подхватит его автоматически.
3. **Номер для записи** — уже указан: `+7 981 196-37-97` (`CONTACTS` в
   `assets/js/data.js`).
4. **Часы работы** — сейчас «Ежедневно · 10:00–22:00», при необходимости
   поменяйте в `CONTACTS.hours`.

## Как работает запись «по СМС»

Это статический сайт без сервера, поэтому кнопка «Отправить СМС мастеру»
открывает у посетителя его собственное приложение сообщений с уже готовым
текстом (имя, телефон, услуга) и номером мастера — оставить нажать «отправить».
Дополнительно есть кнопка «Позвонить мастеру» (обычный звонок). Если нужна
полностью автоматическая отправка СМС без участия посетителя — потребуется
подключение серверного SMS-шлюза (например, SMS.ru/SMSC.ru) с API-ключом,
это уже отдельная задача с бэкендом.

## Как запустить

Сборка не нужна — это чистые HTML/CSS/JS.

```bash
python3 -m http.server 8000
```

Для публикации подойдёт GitHub Pages, Netlify, Vercel или любой хостинг статики.

## Структура

```
index.html              разметка страницы
assets/css/styles.css   стили, тёмная премиальная палитра
assets/js/data.js       ← контакты, преимущества, услуги и цены
assets/js/app.js        рендер прайса, форма записи, меню
images/                 фото мастера (barber.jpg)
```
